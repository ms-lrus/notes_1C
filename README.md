Справочник "Задачи" в 1С

Структура:
1. Наименование задачи
2. Описание задачи
3. Дата создания
4. Срок выполнения

Функции:
1. Создавать новые задачи
2. Редактировать существующие
3. Просматривать список всех задач
4. Искать задачу по наименованию

Интерфейс:
1. Простой и понятный UI
2. Удобный ввод и редактирование
3. Корректная работа поиска
4. Стандартные механизмы платформы
